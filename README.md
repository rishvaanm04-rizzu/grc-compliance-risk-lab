# GRC Compliance & Risk Assessment Lab — Simulated SaaS Environment

## Overview
This repository contains a comprehensive **Simulated GRC Compliance Readiness Assessment** for a fictional SaaS enterprise, **CloudServe Technologies Pvt. Ltd.** The project models end-to-end GRC operations: risk identification, control mapping, gap analysis, policy creation, and audit evidence preparation against **GDPR, DPDPA, SOC 2, and ISO 27001**.

> **Disclaimer:** This repository is a simulated GRC portfolio project created for demonstration purposes. It does not constitute formal legal advice or real-world compliance certification.

---

## Project Structure
* `docs/`
  * `GRC_Readiness_Assessment_Report.pdf` - Complete Master GRC Report
  * `Access_Control_Policy.pdf` - Formal Corporate Access Policy Document
* `artifacts/`
  * `Risk_Register.xlsx` - Risk Identification, Scoring, and Treatment Plan
  * `Compliance_Control_Matrix.xlsx` - Control Objectives and Execution Metrics
  * `Framework_Mapping.xlsx` - Control Mapping across ISO 27001, SOC 2, GDPR, and DPDPA
  * `Gap_Assessment.xlsx` - 5 Key Audit Findings and Recommendations
  * `Remediation_Roadmap.xlsx` - Phased 0–180 Day Action Plan

---

## Key Frameworks Analyzed
* **EU GDPR:** General Data Protection Regulation (Focus: Data Retention & Subject Rights)
* **India DPDPA (2023):** Digital Personal Data Protection Act (Focus: Consent & Data Fiduciary Responsibilities)
* **SOC 2 Type II:** Trust Services Criteria (Security, Confidentiality, Privacy)
* **ISO/IEC 27001:2022:** Information Security Management System (Annex A Security Controls)
